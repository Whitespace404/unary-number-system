# [Unary Number System]

## Basic Details

### Project Description
A fully interactive, client-side educational playground dedicated to celebrating the world's least compact number system: **Unary**.

### The Problem (that doesn't exist)
Number systems at present have too many symbols

### The Solution (that nobody asked for)
The solution is **Unary**. Instead of ten symbols, or two symbols, we use exactly one: `1`. 

"Hold on," you might say. "Unary can only represent positive counting numbers! How on earth do you write negative numbers like -1/2 or fractions like 3/4?
I fixed this problem by creating a bijective mapping from NxN -> N using the Cantor pairing function.

Any number p/q, once passed through my function can be converted into a Natural Number belonging to set N. I represent this number using unary, by showing that many 1s
